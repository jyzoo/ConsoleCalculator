# ConsoleCalculator

Консольный калькулятор на Qt с использованием метаобъектной системы Qt,
сигналов и слотов.

## Цель проекта

Цель лабораторной работы — изучить механизм сигналов и слотов Qt,
наследование от QObject, объявление собственных сигналов и слотов,
установку соединений через QObject::connect(), а также работу
метаобъектной системы Qt (MOC) в консольном приложении.

## Используемые технологии

- C++
- Qt 6
- Qt Core
- Qt Creator
- qmake
- C++17
- Git / GitHub

## Функциональность

Программа поддерживает следующие команды:

```text
add <a> <b>       - сложение
sub <a> <b>       - вычитание
mul <a> <b>       - умножение
div <a> <b>       - деление
reset             - сброс результата
history           - просмотр истории операций
clear_history     - очистка истории
help              - справка
quit              - выход

Архитектура
Проект состоит из следующих основных классов:
Calculator
Класс Calculator наследуется от QObject и содержит слоты
для выполнения арифметических операций:
- add()
- subtract()
- multiply()
- divide()
- reset()
Класс также содержит сигналы:
- resultReady(double)
- errorOccurred(QString)
- operationPerformed(QString)
History
Класс History реализует индивидуальное задание лабораторной работы.
Он наследуется от QObject, хранит список выполненных операций
и содержит слот:
addEntry(QString)

После добавления записи излучается сигнал:
entryAdded(QString)

Связь между классами:
Calculator
    |
    | operationPerformed(QString)
    v
History::addEntry(QString)
    |
    | entryAdded(QString)
    v
Обработчик истории

Обработка ошибок
Программа обрабатывает:
- деление на ноль;
- неправильный формат команды;
- некорректные числовые значения;
- неизвестные команды.
Ошибки передаются через сигнал:
errorOccurred(QString)

Запись результатов
Дополнительно реализована запись успешных результатов
в файл history.txt.
Сигнал resultReady(double) имеет несколько обработчиков:
resultReady
    |
    +----> вывод результата в консоль
    |
    +----> запись результата в history.txt

Это демонстрирует принцип «один сигнал — несколько обработчиков».

Требования
Для сборки необходимы:
- Qt 6;
- Qt Creator;
- Desktop Qt Kit;
- qmake;
- компилятор C++ с поддержкой C++17.
Сборка и запуск
1. Открыть ConsoleCalculator.pro в Qt Creator.
2. Выбрать Desktop Qt Kit.
3. Выполнить Build → Run qmake.
4. Выполнить Build → Build Project.
5. Запустить проект.
Для корректного интерактивного ввода необходимо использовать запуск
приложения в терминале.
Пример работы
> add 5 3
Результат: 8
[История] Добавлена запись: 5 + 3 = 8

> sub 10 4
Результат: 6
[История] Добавлена запись: 10 - 4 = 6

> mul 2.5 4
Результат: 10
[История] Добавлена запись: 2.5 * 4 = 10

> div 10 0
Ошибка: Деление на ноль невозможно!

> history

--- История операций ---
1. 5 + 3 = 8
2. 10 - 4 = 6
3. 2.5 * 4 = 10
------------------------
